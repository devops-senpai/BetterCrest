# Support

Arma is a fork of Crest. Its own support routes are still being set up;
this page says what exists today and marks the rest as placeholders.

## Questions, feedback, and compatibility reports

_Placeholder: Arma has no community forum or chat yet._ Until one
exists, open a [GitHub Issue](https://github.com/devops-senpai/Arma/issues/new/choose)
for questions too, and say in the title that it is a question.

Issues are public. Remove passwords, account details, private URLs, browsing
history, personal messages, and other sensitive information before posting.

## Reproducible bugs and planned work

Use [GitHub Issues](https://github.com/devops-senpai/Arma/issues/new/choose)
when a report has a Arma version, Apple platform, repeatable steps,
expected result, and actual result. Search existing issues first and add
sanitized evidence only when it changes what another person can reproduce.

_Placeholder: Arma has no public roadmap or release milestones yet._

## Security vulnerabilities

Use GitHub's
[private vulnerability report](https://github.com/devops-senpai/Arma/security/advisories/new).
Do not post suspected vulnerabilities in a public issue. See
[SECURITY.md](SECURITY.md) for scope and reporting guidance.
