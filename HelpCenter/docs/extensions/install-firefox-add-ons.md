# Firefox add-ons

BetterCrest does not install Firefox add-ons from **addons.mozilla.org**.

Extensions in BetterCrest for Mac run on the Chromium engine, which runs Chrome extensions from the Chrome Web Store. It cannot load a Firefox `.xpi` package. WebKit pages, and BetterCrest on iPhone and iPad, run no extensions.

Many Firefox add-ons also publish a Chrome version. Look for the same extension in the Chrome Web Store and install it from there. See [Install from the Chrome Web Store](./install-chrome-web-store.md).

If you installed Firefox add-ons in an earlier version of BetterCrest, they do not carry over. Install each extension's Chrome version into the Space you want.
